주요 기능

Hybrid RAG/FAQ 엔진

AWS Bedrock Knowledge Base의 문서 검색 역량과 PostgreSQL/Redis 기반의 고속 FAQ 검색을 결합하여 답변 정확도와 응답 속도를 동시 확보

지능형 FAQ 자동 생성 파이프라인

Celery 비동기 작업을 활용하여 신뢰도가 높은 RAG 답변을 FAQ 후보로 자동 생성하고, 의미 기반 클러스터링을 통해 지식 베이스를 최신화

다층 가드레일 및 보안 설계

Prompt Injection 방지 로직과 블랙리스트, 민감 정보 마스킹을 적용하고 Guardrail 노드를 통해 부적절한 콘텐츠의 생성을 원천 차단

뉴스 브리핑

매일 자동 수집된 IT 뉴스를 요약 브리핑하는 부가 서비스 구현

시스템 아키텍처

Clean Architecture (Port/Adapter) 기반의 모듈화된 챗봇 구조

트러블슈팅

대량 로그 및 데이터 처리 지연 문제

채팅 로그 저장 및 FAQ 후보 생성 과정에서의 API 응답 지연을 Celery + Redis 기반 비동기 큐 시스템 도입으로 시스템 부하를 성공적으로 분산

AWS Bedrock Inference Profile 설정 오류

특정 모델(Claude Haiku 4.5) 호출 시 발생하는 타임아웃 및 권한 문제를 고유 Inference Profile ARN 수동 매핑 및 자격 증명 최적화로 해결

검색 임계값 설정에 따른 답변 품질 저하
