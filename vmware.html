vSphere 기반의 고가용성(HA/FT) 인프라 및 가상화 서버 운영 환경 구축

주요 기능

Enterprise High Availability (HA & FT)

호스트 장애 발생 시 가상머신을 다른 호스트에서 자동으로 재구동하는 HA와, 세컨더리 VM을 통해 데이터 유실 없이 즉시 전환하는 Fault Tolerance(FT)를 구현하여 인프라의 무중단 운영을 실현했습니다.

Dynamic Resource Management (DRS & vMotion)

서비스 중단 없는 실시간 VM 이동 기술인 vMotion을 구축하고, DRS(Distributed Resource Scheduler)를 통해 클러스터 내 호스트 간 자원 부하를 자동으로 분산 최적화했습니다.

Shared Storage Architecture (iSCSI & NFS)

iSCSI 프로토콜을 활용한 공유 스토리지를 구성하여 데이터 중심적인 클러스터 환경을 구축했습니다. 이를 통해 VM의 이동성을 보장하고 데이터 정합성을 확보했습니다.

Advanced Infrastructure Services

Active Directory(AD) 기반의 도메인 환경, NTP 서버를 통한 시간 동기화, DNS 서버 구축 등 엔터프라이즈 급 인프라 운영에 필수적인 핵심 서비스를 직접 구성했습니다.

시스템 아키텍처

ESXi 클러스터와 물리적으로 분리된 전용 네트워크망을 갖춘 엔터프라이즈 인프라 구조

보안과 성능 최적화를 위해 네트워크 트래픽을 물리적/논리적으로 분리 설계했습니다. 관리(Management), 스토리지(Storage), vMotion, FT 전용 네트워크를 각각 별도의 vSwitch와 VLAN으로 구성하여 트래픽 간섭을 최소화하고 안정성을 극대화했습니다.

트러블슈팅 (Lessons Learned)

vCenter 부팅 인식 오류 및 스토리지 구성 문제

vCenter 서버 구축 후 부팅 드라이브를 인식하지 못하는 현상을 BIOS 레벨에서 디버깅하여 해결했습니다. 이 과정에서 가상화 환경에서의 하드웨어 에뮬레이션과 스토리지 컨트롤러 설정의 중요성을 학습했습니다.

FT(Fault Tolerance) 리소스 부족 및 환경 이전

로컬 워크스테이션의 자원 한계로 FT 활성화가 실패하는 문제를 해결하기 위해, 128GB RAM 사양의 전용 서버로 인프라를 이전하고 Nested ESXi 구조를 재설계하여 고가용성 기능을 완벽하게 구현했습니다.

환경 이전 후 네트워크 단절 이슈

물리 장비 이동 후 IP 충돌 및 네트워크 설정 불일치로 발생한 접속 불가 현상을 vSphere Standard Switch 설정을 초기화하고 정적 IP 할당 정책을 재수립하여 해결했습니다.
