주요 기능 (Auth Domain)

소셜 로그인 및 토큰 기반 인증

Google 및 Kakao OAuth2 연동을 통한 자동 회원가입 프로세스를 구현하고, Access/Refresh Token 분리 관리를 통해 보안성이 높은 무상태(Stateless) 인증 시스템 구축

초대 코드 기반 커플 매칭 시스템

사용자 간의 양방향 연결을 위한 6자리 초대 코드 생성 및 검증 로직을 구현했으며, 매칭 완료 시 CoupleId를 포함한 JWT 재발급을 통해 세션 정보를 실시간 갱신

MSA 통합 보안 아키텍처 수립

API Gateway와 연동하여 모든 외부 요청에 대한 인증을 전처리하고, 내부 마이크로서비스로 사용자 식별 정보(X-User-Id)를 커스텀 헤더를 통해 안전하게 전달

TSID 기반 분산 ID 설계 및 성능 최적화

분산 환경에서의 ID 충돌을 방지하고 삽입 성능을 극대화하기 위해 TSID(Time-Sorted ID)를 도입했으며, 주요 조회 필드에 대한 인덱스 전략으로 응답 속도 체감 개선

시스템 아키텍처

Auth 서비스를 중심으로 한 MSA 도메인 분리 및 데이터 흐름

트러블슈팅

분산 환경에서의 인증 정보 전파 이슈

Gateway에서 인증된 사용자 정보를 각 마이크로서비스가 매번 DB 조회 없이 식별해야 하는 문제를 Custom Header 기반 Context 전파와 JWT 메모리 검증 방식으로 해결

OAuth2 로그인 시 사용자 데이터 동기화 지연

소셜 서비스의 최신 정보와 내부 DB 정보가 불일치하는 문제를 OAuth2 Success Handler 단계의 실시간 동기화 로직 및 Dirty Checking을 활용하여 신뢰도 확보

보안 필터 체인의 응답 지연 최적화

불필요하게 긴 Filter Chain 실행으로 인한 성능 저하를 방지하기 위해 OncePerRequestFilter 도입 및 화이트리스트 기반 필터 스킵 로직을 적용하여 p95 응답 속도 개선
